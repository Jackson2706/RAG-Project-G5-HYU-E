# School of Computer Science — careers

## School of Computer Science — PDF page 11 — careers

Businesses: Domestic and international internet service providers, electronics companies, computer developers, game developers, animation-related companies, companies that need to develop software, and all companies that need to manage computer systems on their own, such as public companies and financial institutions, mobile programming companies, web programming companies, video production companies, etc.

Public sector: Central government ministries, Korea Creative Content Agency, Korea Software Agency, National Intelligence Service, and other government-funded agencies and research centers, such as Electronics and Telecommunications Research Institute

Technology and development: Computer engineers, application software developers, system software developers, computer security specialists, web developers, database administrators, network system analysts and developers, multimedia planners, etc.

Administrators: System operators and administrators, database administrators, etc.
