## Full crawl review (Claude Code, 2026-11-10)

The human's full crawl took 59 minutes (3,565 s): 1,423 requests, all HTTP 200 except 5 × 403. Those 5
are attachments of `sub4_01/1810217`, which the server forbids. robots.txt skipped nothing. Seoul `/`
and `/staff` were denied. Snapshot `hyu-20261110-2935ce83` held 356 documents (308 Seoul, 48 ERICA).
The review found five more bugs. Fixing them requires rebuilding that snapshot:

| # | Bug | Fix | Test |
|---|---|---|---|
| 6 | 7 e-mail addresses were not masked. They were broken by PDF line ends (`x@mofa.go.k` + newline), ran into the next word (`x@sogang.ac.kr51`), or ended a sentence (`x@hanyang.ac.kr.`). | Greedy `EMAIL_RE`; it masks a little too much rather than leak. | `test_broken_and_run_on_emails_are_masked` |
| 7 | None of the 8 ERICA attachments were parsed. The link text ends with the size, `Guide.pdf (4.2M)`, so the type became `.2m)`. These are the Leave of Absence and Return-to-school guidelines. | Strip the size suffix; take the type from the filename, else from the Content-Type. | `test_attachment_type_ignores_gnuboard_size_suffix_and_falls_back_to_content_type` |
| 8 | Seoul Forms attachments named only `.docx` or `.pdf` gave `unknown`, so they were not parsed. | Same helper. | same test |
