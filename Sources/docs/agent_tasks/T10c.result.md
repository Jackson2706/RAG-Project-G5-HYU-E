# T10c result: automated tag audit

## What changed

- Added `labeling.auto_audit` with the `sample`, `compare`, and `finalize` commands.
- `sample` reads MongoDB, applies the A14 bucket and campus strata, enforces the TOPIK,
  `rule_unconditioned`, and `any_of` floors, and writes the blind inputs and private sample
  metadata under `Report/results/tag_audit/<index_id>/auto/`.
- `compare` validates blind reference rows against vocabulary v1 and their evidence quotes. It
  scores value-level TP, FP, and FN by attribute, rule/LLM family, bucket, and campus. The reports
  include Wilson 95% intervals, bucket-weighted recall, and `any_of` exact match. Disagreement sides
  are shuffled with the sample seed, while the side key stays in a separate file.
- `finalize` applies `a`, `b`, `both_wrong`, and `ambiguous` decisions through the private key. It
  excludes ambiguous rows, re-scores the final reference, and writes the G2 report with the required
  disagreement, out-of-vocabulary, audience, and TOPIK-scope counts.
- Updated the tag-audit section of `docs/aaes_spec.md` for the A14 workflow.
- Added offline tests with synthetic MongoDB indexes and hand-computed score examples.

## Skipped or not checked

- The published MongoDB index was not queried because the task forbids agents from running the
  audit and the local services were unavailable. The tests use synthetic records with the same
  document, chunk, applicability, bucket, and manifest structure.
- No annotation pass, disagreement review, crawl, index build, or evaluation run was performed.
- `Report/project/STATUS.md` was not updated because T10c limits writes to the four paths listed in
  the task specification.
- Ruff was not available in the existing environment. Python compilation, the required tests, and
  `git diff --check` passed without installing another tool.

## Risks

- MongoDB stores the current section but not the complete heading hierarchy. The blind export uses
  a stored `heading_path` when available and otherwise emits the section as a one-element path.
- The weighted-recall interval uses the same raw-sample Wilson approximation as
  `labeling.audit_tags`. A result close to a G2 threshold should be checked with a bootstrap before
  the gate is approved.

Human runs: nothing.
