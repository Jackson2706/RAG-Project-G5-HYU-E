# T07 — SciFact mapping check result

Owner: Codex · Phase: P3 · Date: 2026-11-10

## What changed

- Added `evaluation.scifact_mapping`, an offline CLI that maps BEIR SciFact query IDs to original
  SciFact claims after integer normalization.
- The report checks normalized claim text, counts matched labels, compares qrels with evidence and
  cited document sets, counts NEI claims with qrels, and reports original claims absent from BEIR.
- The CLI prints a compact Markdown table and writes `mapping.json` and `mapping.md`, including the
  MD5 values read from both datasets' `SOURCE.json` files. It stores at most 20 unmatched IDs and
  five text mismatch examples.
- Missing data exits with code 2, without a traceback, and prints
  `python -m evaluation.runner --download scifact,scifact_original`.
- Added an offline test that reuses the T06 original SciFact fixture through `tmp_path` and creates
  a tiny BEIR-format fixture. The expected report asserts every requested count, both output files,
  the printed table, and missing-data behavior.
- Documented the command and output location in the benchmark guide.
