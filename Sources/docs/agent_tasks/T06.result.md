# T06 — Benchmark adapters result

Owner: Codex · Phase: P3 · Date: 2026-11-10

## What changed

- Added a shared `SOURCE.md` writer. BEIR downloads now write it after a fresh download and
  backfill it from `SOURCE.json` on a cached download without a network request.
- Added the original SciFact adapter. It verifies the published MD5, records SHA-256, rejects
  unsafe tar paths, skips cross-validation folds, flattens the four required files, merges
  rationale sentence sets, and returns SUPPORT, CONTRADICT, NEI, or MIXED claim labels.
- Added the ConditionalQA adapter. It downloads four files from the pinned commit through `.part`
  files, records first-download SHA-256 values, enforces them on later calls, normalizes question
  records, and converts document HTML elements into headed `ParsedDocument` sections.
- Extended `--download` dispatch to accept all three BEIR names plus `scifact_original` and
  `conditionalqa`. No evaluation task or configuration uses the two new adapters yet.
- Added offline fixtures and tests for label normalization, rationale merging, conflicting labels,
  tar safety and fold exclusion, checksum failure, ConditionalQA questions and sections,
  trust-on-first-download checksums, provenance Markdown, and cached BEIR backfill.
- Documented both adapter-only datasets, their integrity rules, licences, and download command.

## Skipped checks and risks

- The agent did not run a dataset download, index build, smoke run, full evaluation, or database
  mutation. Benchmark files that appeared under `Report/data/benchmarks/` during the task were
  human-owned and left outside this change set.
- ConditionalQA has no published checksums. Its pinned commit reduces source drift, but integrity
  remains trust-on-first-download: later downloads are checked against the locally recorded
  SHA-256 values.
- The original SciFact test claims and ConditionalQA test answers remain unavailable through the
  labeled loaders by design.
- `Report/project/STATUS.md` and `Report/ai_use_statement.md` were not updated because T06 permits
  writes only to its explicit allowlist, which excludes both files.
