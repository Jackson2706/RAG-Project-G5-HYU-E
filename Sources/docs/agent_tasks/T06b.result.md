# T06b: Benchmark loader fixes result

Owner: Codex · Phase: P3 · Date: 2026-11-10

## What changed

- Fixed the ConditionalQA test loader so `not_answerable`, `answers`, and `evidences` are `None`
  when the published row omits them. Train and dev retain their labeled types.
- Fixed the ConditionalQA document loader for the published list structure. It returns a mapping
  keyed by URL and raises `ValueError` when two rows use the same URL.
- Updated the original SciFact claim loader to accept the public test split. Missing
  `cited_doc_ids`, `evidence`, and `label` values are returned as `None`. Corpus keys, cited
  document IDs, and evidence keys remain strings even though the published corpus uses integer
  `doc_id` values.
- Rebuilt the ConditionalQA fixtures with list-based documents, separate HTML elements, labeled
  train/dev rows, and a test row containing only its four published fields. The labeled examples
  cover answers with and without conditions and a not-answerable question.
- Added original SciFact dev and test fixtures. The fixture set covers labeled claims, empty
  evidence, an unlabeled test claim, and integer corpus document IDs.
- Added real-data smoke tests for BEIR SciFact, NFCorpus, ArguAna, original SciFact, and
  ConditionalQA. Each test skips with the missing file path when its local data is absent.

## ConditionalQA document statistics

The local pinned dataset contains 652 documents. Parsing them produced 13,072 sections. Sections
per document have a minimum of 3, a median of 16, and a maximum of 100. Every document produced at
least one section.

The official root-level
[`evaluate.py`](https://github.com/haitian-sun/ConditionalQA/blob/77bd295952daf415548b3244db10880d3d55cfe0/evaluate.py)
exists at pinned commit `77bd295952daf415548b3244db10880d3d55cfe0`. It was checked in the upstream
repository and was not downloaded. A3 needs this script to reproduce the dataset's official answer
and condition metrics.
