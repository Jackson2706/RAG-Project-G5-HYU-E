# T08d result

Owner: Codex. Phase: P4. Date: 2026-11-11.

## What changed

- Every chunk in an admission guide now gets `academic_status=applicant`. Acceptance-procedure
  chunks get `admitted_not_enrolled`, and leave-of-absence information inside an admission guide
  stays applicant-scoped.
- Academic status now comes from stated wording. Leave-of-absence application notices target
  enrolled students, while return-to-school and re-registration notices target students on leave.
- Parenthesized and colon-delimited ineligibility lists no longer add `student_type`,
  `degree_level`, or `academic_status`. `Degree Program Students` maps to `degree_seeking`.
- Year extraction unions every explicit numeric or ordinal study-year range in a chunk. It does
  not treat scholarship and leave durations as study years.
- Visa changes keep only the target visa, including OCR-spaced codes and `from ... to ...` wording.
- Rule 5b removes TOPIK constraints and TOPIK `any_of` sets when an alternative is outside
  vocabulary v1. The source sentence or `Sort:` row is kept as a requirement of at most 200
  characters. The TOPIK-or-English rule is unchanged.
- `rule_cue_unknown` follows `rule_unconditioned` in `TAG_BUCKETS`. With the fallback disabled, an
  otherwise untagged chunk with an LLM cue enters that bucket without resolving or calling a model.
  The pipeline stores its `condition_status` as `unknown`.
- The dry run now prints the complete partition estimate and the requested r4 rule counters.
- `aaes_spec.md` documents the r4 tagging rules and the rules-only unknown bucket.
