# T10b result

## Changes

- The 50-chunk sampler now requires at least six chunks whose `topik_level` extraction method is
  `llm`. The command prints this achieved count with the existing T10 strata.
- Sampling writes `<csv stem>.meta.json` beside the review sheet. It records `index_id`, `seed`,
  `n`, `stratum_counts`, and the six-bucket `bucket_partition` copied from
  `manifest.applicability.partition`. Scoring stops with a clear error when this file is absent or
  its partition is invalid.
- The sheet adds `out_of_vocabulary_condition` and `audience` before `reviewer`. Audience values
  are limited to `applicant`, `admitted`, and `enrolled`, with `|` between multiple values.
- Precision, raw recall, and bucket-weighted recall now include Wilson 95% intervals in the JSON
  and Markdown reports. Every existing attribute, method, bucket, and campus split carries the
  intervals. Buckets present in the index but absent from the reviewed sample are listed and left
  out of the weighted estimate.
- The Markdown report has the Gate G2 attribute table and rule/LLM summary rows. Gate G2 uses
  precision of at least 0.8 and weighted recall of at least 0.7 for attributes with at least five
  occurrences. The report also counts out-of-vocabulary conditions and audience values.
- The synthetic index now has twelve LLM-extracted TOPIK chunks and a complete manifest
  partition. Tests cover the Wilson example, hand-computed weighted recall, an unsampled bucket,
  a missing sidecar, audience validation, the TOPIK floor, and the new report fields.

## Filling the two new columns

- In `out_of_vocabulary_condition`, enter one concise eligibility condition stated by the chunk
  that the current attribute vocabulary cannot represent, such as `GPA >= 3.0` or `nationality`.
  Leave it blank when the vocabulary already represents every stated condition or the chunk has
  no such condition. Do not copy the phrase into an attribute's `missed` cell.
- In `audience`, enter `applicant`, `admitted`, or `enrolled` only when the chunk applies to that
  stage. Join several applicable stages with `|`, for example `admitted|enrolled`. Leave it blank
  when the text does not identify an audience.
- These columns do not affect precision, recall, or the G2 verdict. Continue to partition every
  predicted value between `correct` and `wrong`, add absent true vocabulary values to `missed`,
  and sign each completed row in `reviewer`.
