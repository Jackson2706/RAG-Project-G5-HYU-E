# T41 result: trace expiry and stored-history deletion

Implemented by Codex on 2026-11-20.

## Changes

- Added `Settings.trace_ttl_days`, defaulting to 30 and configurable through `TRACE_TTL_DAYS`. Negative values fail settings validation.
- `save_trace` stores a UTC BSON Date in `expires_from` without changing `created_at` or the caller's trace dictionary.
- Index setup backfills missing expiry dates from ISO strings or BSON Dates. Naive timestamps are treated as UTC. Invalid or missing timestamps stay untouched, and a warning reports their count.
- Index setup creates the TTL index with the configured number of seconds, or sends `collMod` to update an existing index. It preserves collections and existing expiry timestamps.
- Added localhost-only `GET /api/traces` for the confirmation count and `DELETE /api/traces`, which returns the actual deleted count. The client address must be `127.0.0.1`, `::1`, or `testclient`; forwarded headers do not bypass the check.
- Help now offers **Delete stored history**, an in-page confirmation with Delete and Cancel, a success count, and error text. It disables repeated requests while one is pending. Cancel sends no deletion request; `window.confirm` is never called.
- Updated the privacy check and reviewed the changed prose with Humanizer against `Report/voice_sample.md`.

## Limits and risks

MongoDB removes expired traces asynchronously. Legacy traces with unparseable dates do not expire automatically but remain deletable. The count can change between confirmation and deletion; the success message uses the deletion result. Later or in-flight chat requests may store new traces after deletion.

Retention setup and the management endpoints target the application's trace collection (`hyu_compass.traces` by default), as specified in T41. Independently stored traces in benchmark/index databases are not migrated or cleared by these endpoints. Deleting stored traces leaves the current conversation in browser memory.

Live MongoDB TTL scheduling, live `collMod`, and the UI screenshot were not checked. Claude Code owns screenshot u16. No crawl, download, index build, or live evaluation was run. Other changes appeared in the shared worktree during this task and were left untouched.

Only T41's allowed repository paths were edited. `STATUS.md` and `ai_use_statement.md` were excluded by that allowlist. No commit or push was made.
