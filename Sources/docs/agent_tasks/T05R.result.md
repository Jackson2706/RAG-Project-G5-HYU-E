- `REPORT_DIR` is defined before `DATA_DIR` and `RESULTS_DIR`. The latter two now default to
  `Report/data/` and `Report/results/`, and both follow an `HYU_REPORT_DIR` override unless their
  own override is set.

  values through the configured directories. Report regeneration now uses it for annotations, so
  old run manifests still work and a missing annotation file still produces N/A answer metrics.

  name the two-folder layout. Stored manifest and snapshot paths were not rewritten.
- The committed-snapshot test verifies both checksums, all 362 document rows, required row fields,
  and the manifest-derived snapshot suffix. The existing crawler dry-run test still passes.
