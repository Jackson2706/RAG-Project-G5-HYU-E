## What changed

- `Sources/backend/app/config.py` now defines `REPO_ROOT`, `DATA_DIR`, `RESULTS_DIR`, and
  `REPORT_DIR`. The three repository directories read their `HYU_*_DIR` overrides at import time,
  and `Settings.data_dir` defaults to `DATA_DIR`.
- The BEIR cache now uses `data/benchmarks/`, evaluation runs use `results/<run-id>/`, and report
  annotations and HYU fixtures resolve from the repository-level `data/` tree. Evaluation configs
  remain in `Sources/evaluation/configs/`.
- Backend fixtures, the ingest API and CLI, setup guidance, retrieval errors, and the UI now use
  folders relative to `DATA_DIR`: `HYU/raw` and `HYU/synthetic_fixture`.
- Shell scripts continue to change into `Sources/` and use its `backend/`, `frontend/`, `.env`, and
  `.run/` paths. `uninstall.sh` now identifies repository data and results outside `Sources/`.
- `.gitignore` now follows the reorganized paths. Downloaded benchmark contents are ignored while
  `data/benchmarks/*/SOURCE.md` remains committable. Required `.gitkeep` files were added under
  `data/HYU/` and `Report/`.
- `README.md` and the six main files in `Sources/docs/` now show the reorganized tree, commands run
  from `Sources/`, and the new data and result locations.
- A backend test reloads `app.config` with monkeypatched environment variables and checks both the
  repository defaults and all three overrides.

Docker Compose still declares `name: hyu-compass` and the `mongodb_data` and `qdrant_data` volume
keys; T02 did not change it.
