Seoul attachments:
- They are inline `<a href="/?module=file&act=procFileDownload&file_srl=N&sid=...&module_srl=M">`
  links inside the body. The link text is the filename.
- The download 302-redirects to `/file/procFileOutput?file_srl=N&file_key=...`. Follow the redirect.
- Key attachments on `file_srl` only, because `sid` and `file_key` change.
- Fetch only attachments whose filename looks English, or has no Hangul/CJK:
  - skip names with `(kor)`, `(국문)`, `(Korean)`, `(中文)`, `(중문)`;
  - keep names with `eng`, `(영문)`, `(English)`.

Seoul body language:
- In a trilingual post, each `<p>` holds one language. The Korean paragraphs come first, then
  English, then Chinese, so `<p>`-level blocks work for the language filter.
- Titles are often bilingual, e.g. `[생활] 외국인 ... Guide on National Health Insurance ...`.
  Keep the English part of the title.

Seoul sitemap:
- 1111 URLs: 1046 `/notice/<id>`, 31 `/sub4_01/<id>`, 6 `/Forms/<id>`, and about 28 static pages.
- Exclude `/staff` (staff directory, a data rule).
- Most notices are Korean-only. Expect many documents with English coverage near 0 to be skipped
  with a warning.
