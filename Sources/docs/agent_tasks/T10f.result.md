# T10f result: G2b resolved and strict scoring

## What changed

- Added repeatable `sample --quota BUCKET=N`. An explicit quota replaces that bucket's scaled
  default and remains exact while unlisted buckets supply any fill chunks. The G2b sample command
  uses `--n 100 --quota rule_cue_unknown=30`.
- Split attribute scoring into resolved and strict views. Constraint attributes on stored
  `condition_status=unknown` chunks are excluded from resolved precision, recall, and weighted
  recall, while their reference values are strict misses. Campus, scope, and effective term remain
  resolved on every chunk.
- Added per-attribute coverage, strict recall, strict weighted recall, and Wilson 95% intervals.
  Gate G2b still uses resolved precision >= 0.8 and resolved weighted recall >= 0.7 for attributes
  with at least five reference occurrences.
- Added the sampled unknown-condition share, its Wilson interval, the estimate scaled to the index
  unknown count, the scaled interval, and the most frequent reference attributes in conditioned
  unknown chunks.
- Added `report --side-by-side OUT_A OUT_B --to FILE.md`. It reads both `scores_final.json` files,
  puts their final per-attribute scores and gates in one table, and reports both unknown-condition
  estimates. The limitation statement is the first line.
- Updated the Tag audit section of `Sources/docs/aaes_spec.md` and added offline synthetic tests for
  the hand-computed five-chunk scores, unknown estimate, quota override, and side-by-side report.

## G2b command sequence

Run from `Sources/` when the r4 audit is executed. The old sample reuses the r3 blind inputs and the
separate rule-8b reference. Review steps create the indicated `decisions.jsonl` files before
`finalize`.

```bash
python -m labeling.auto_audit sample \
  --index-id hyu_20261110_97dc1269_r4 \
  --reuse ../Report/results/tag_audit/hyu_20261110_97dc1269_r3/auto/sample_meta.json \
  --out reuse_r3

python -m labeling.auto_audit compare \
  --index-id hyu_20261110_97dc1269_r4 \
  --reference ../Report/results/tag_audit/hyu_20261110_97dc1269_r3/auto/reference_r8b.jsonl \
  --carry-decisions ../Report/results/tag_audit/hyu_20261110_97dc1269_r3/auto \
  --out reuse_r3

# Review reuse_r3/disagreements.jsonl blind and write reuse_r3/decisions.jsonl.

python -m labeling.auto_audit finalize \
  --index-id hyu_20261110_97dc1269_r4 \
  --reference ../Report/results/tag_audit/hyu_20261110_97dc1269_r3/auto/reference_r8b.jsonl \
  --decisions ../Report/results/tag_audit/hyu_20261110_97dc1269_r4/reuse_r3/decisions.jsonl \
  --out reuse_r3

python -m labeling.auto_audit sample \
  --index-id hyu_20261110_97dc1269_r4 \
  --n 100 \
  --quota rule_cue_unknown=30 \
  --exclude ../Report/results/tag_audit/hyu_20261110_97dc1269_r3/auto/sample_meta.json \
  --out fresh

# Annotate fresh/blind_inputs.jsonl without predicted tags and write fresh/reference.jsonl.

python -m labeling.auto_audit compare \
  --index-id hyu_20261110_97dc1269_r4 \
  --reference ../Report/results/tag_audit/hyu_20261110_97dc1269_r4/fresh/reference.jsonl \
  --out fresh

# Review fresh/disagreements.jsonl blind and write fresh/decisions.jsonl.

python -m labeling.auto_audit finalize \
  --index-id hyu_20261110_97dc1269_r4 \
  --reference ../Report/results/tag_audit/hyu_20261110_97dc1269_r4/fresh/reference.jsonl \
  --decisions ../Report/results/tag_audit/hyu_20261110_97dc1269_r4/fresh/decisions.jsonl \
  --out fresh

python -m labeling.auto_audit report \
  --side-by-side \
    ../Report/results/tag_audit/hyu_20261110_97dc1269_r4/reuse_r3 \
    ../Report/results/tag_audit/hyu_20261110_97dc1269_r4/fresh \
  --to ../Report/results/tag_audit/hyu_20261110_97dc1269_r4/g2b_side_by_side.md
```
