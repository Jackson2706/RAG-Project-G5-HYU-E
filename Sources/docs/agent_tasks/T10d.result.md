# T10d result: r4 audit sampling and comparison

## What changed

- Added `rule_cue_unknown` to the audit bucket order. False negatives in that bucket belong to the
  rule family. A missing `rule_cue_unknown` count is read as zero for pre-r4 manifests and sample
  metadata; other missing buckets remain errors.
- Added `--out NAME` to `sample`, `compare`, and `finalize`. The default remains `auto`, and each
  command writes under `Report/results/tag_audit/<index_id>/<NAME>/`.
- Scaled bucket quotas and sampling floors from the 150-chunk defaults. Empty buckets receive no
  quota. Floor metadata records requested, available, required after capping, and achieved counts.
- Added repeatable `sample --exclude META`. Excluded chunk IDs are removed before quotas and floors
  are calculated, and each metadata path and chunk count is recorded.
- Added `sample --reuse META`. It preserves the source chunk order, recalculates bucket and campus
  strata from r4, uses the r4 partition, rejects missing chunks or changed text, and copies the old
  blind input without rewriting it.
- Added `compare --carry-decisions DIR`. A decision is carried only when the chunk ID, attribute,
  and both value sets match. Side labels are remapped when `a` and `b` are reversed. The reviewer
  sees only new disagreements, while `finalize` combines carried and new decisions and reports the
  carried count.
- Updated the AAES tag-audit specification and added offline mongomock tests for the r4 rules-only
  partition.

## Exact r4 command sequence

Run these commands from the repository root after r4 is published. The first reference path is the
separate rule-8b recheck required by PLAYBOOK A21; the original r3 reference stays unchanged.

```bash
cd Sources

python -m labeling.auto_audit sample \
  --index-id hyu_20261110_97dc1269_r4 \
  --reuse ../Report/results/tag_audit/hyu_20261110_97dc1269_r3/auto/sample_meta.json \
  --out reuse_r3

python -m labeling.auto_audit compare \
  --index-id hyu_20261110_97dc1269_r4 \
  --reference ../Report/results/tag_audit/hyu_20261110_97dc1269_r3/auto/reference_rule8b.jsonl \
  --carry-decisions ../Report/results/tag_audit/hyu_20261110_97dc1269_r3/auto \
  --out reuse_r3

python -m labeling.auto_audit sample \
  --index-id hyu_20261110_97dc1269_r4 \
  --n 100 \
  --exclude ../Report/results/tag_audit/hyu_20261110_97dc1269_r3/auto/sample_meta.json \
  --out fresh

python -m labeling.auto_audit compare \
  --index-id hyu_20261110_97dc1269_r4 \
  --reference ../Report/results/tag_audit/hyu_20261110_97dc1269_r4/fresh/reference.jsonl \
  --out fresh

python -m labeling.auto_audit finalize \
  --index-id hyu_20261110_97dc1269_r4 \
  --reference ../Report/results/tag_audit/hyu_20261110_97dc1269_r3/auto/reference_rule8b.jsonl \
  --decisions ../Report/results/tag_audit/hyu_20261110_97dc1269_r4/reuse_r3/decisions.jsonl \
  --out reuse_r3

python -m labeling.auto_audit finalize \
  --index-id hyu_20261110_97dc1269_r4 \
  --reference ../Report/results/tag_audit/hyu_20261110_97dc1269_r4/fresh/reference.jsonl \
  --decisions ../Report/results/tag_audit/hyu_20261110_97dc1269_r4/fresh/decisions.jsonl \
  --out fresh
```

The two `compare` commands produce the disagreement files. The reference and decision review steps
must be completed before their corresponding `compare` and `finalize` commands.
