# T12 result — labeling tools

Completed on 2026-11-10.

## What changed

- Added `labeling.search`, a BM25 search over individual snapshot spans and heading-to-next-heading
  section windows. Results preserve the snapshot row's exact character offsets and can be filtered
  by campus.
- Added `labeling.validate`, which checks the Appendix D schema, annotator and origin formats,
  applicability vocabulary, profile consistency, evidence offsets and version links, behavior
  rules, and unique case IDs. It imports the vocabulary from the backend instead of copying it.
- Added `labeling.agreement`, which reports Cohen's kappa, branch-attribute Jaccard, and
  character-level evidence-span F1. It writes `agreement.md` and an adjudication CSV with empty
  final-decision columns.
- Added `labeling.freeze`, which makes the seeded, largest-remainder split stratified by slice and
  campus, writes sha256sum-compatible hashes, makes `test.jsonl` read-only, refuses to overwrite a
  freeze, and provides both `verify` and `verify_frozen`.
- Added synthetic tests in the real snapshot row structure, hand-computed metric tests, validation
  cases for every specified rule, adjudication output checks, and a committed-snapshot search smoke
  test. The prewritten `labeling/tests/test_freeze.py` was not changed.

## CLI examples

Run these from `Sources/` after `conda activate RAG`:

```bash
python -m labeling.search "part-time work hours" --snapshot hyu-20261110-97dc1269 --k 10 --campus erica
python -m labeling.validate ../Report/data/HYU/labels/codex-draft.jsonl --snapshot hyu-20261110-97dc1269
python -m labeling.agreement ../Report/data/HYU/labels/codex.jsonl ../Report/data/HYU/labels/claude.jsonl --out ../Report/data/HYU/labels/agreement
python -m labeling.freeze ../Report/data/HYU/labels/final.jsonl --out ../Report/data/HYU/labels --dev-size 50 --seed 13
```
