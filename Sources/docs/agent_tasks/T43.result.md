`--case-major` runs the ready presets in planned order for each case, preserving the order returned
by `load_cases`. Both run orders use `run_hyu_case` for the pipeline call and record conversion.
Records still append to each task's existing raw file. Resume uses `read_done`, skips completed
pairs, and retries failed records. The existing resume, force, and result-file safeguards remain.
Without `--case-major`, execution still runs one preset at a time.

`--stop-at` requires an ISO 8601 timestamp with a UTC offset. Both flags require `--suite hyu`.
The runner checks the deadline before starting a case that needs work. Once a case starts, every
pending preset for that case finishes before the next deadline check. Fully recorded cases skip
without a pipeline call or a clock check.

At the deadline, the runner prints `STOP_AT reached after N complete cases`, marks unfinished
tasks `STOPPED`, records their completed-query count and an offset-aware `stopped_at`, and writes
reports. Tasks with completed records for every requested case remain `COMPLETED`. A deadline
stop exits successfully; separate `FAILED` or `BLOCKED` tasks still cause a nonzero exit.
